# Tests à écrire

Dans ce projet de tests, ajoutez progressivement les méthodes de test demandées
par les exercices. Respectez Arranger, Agir et Auditer; construisez directement
la classe testée sans utiliser le conteneur d’injection de dépendances.

- E01 : un scénario avec un espion manuel, puis son équivalent avec Moq;
- E02 : deux méthodes de test;
- E03 : un scénario avec l’espion, puis son équivalent avec Moq.

La duplication entre les deux styles de test est intentionnelle : elle permet
de comparer ce que la classe manuelle rend explicite et ce que Moq condense.

# Zone commune du TP01

Conserver ici les conventions et la procédure d'intégration. Aucun projet partagé n'est nécessaire au départ. N'y déplacer aucune entité métier ni service des lots. Chaque solution individuelle doit compiler sans ce dossier et sans les autres lots; un type partagé facultatif ne doit pas devenir une dépendance bloquante.

Une fonctionnalité entre lots est facultative et ne donne pas de points supplémentaires. Si elle est ajoutée, garder le parcours individuel autonome comme mode de référence; utiliser un contrat stable et une doublure locale, sans référence vers un projet de l'autre lot.

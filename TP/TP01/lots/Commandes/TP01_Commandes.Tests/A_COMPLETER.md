# Tests individuels — Commandes

Le projet est fourni sans tests métier : écrire les tests AAA de votre lot selon `DONNEES.md` et votre fiche de lot. La compilation du départ ne prouve pas que le TP est réalisé. Construire directement les sujets testés; les objets déterministes sont réels. Une doublure du contrat `IDepotCommandes` peut observer les appels ou simuler un incident sans aucun projet d'un coéquipier.

Conserver les tests des invariants, du cas d'utilisation, du dépôt mémoire et du détail technique. Vérifier les préconditions publiques et les refus attendus. Les fichiers de test utilisent des dossiers temporaires isolés.

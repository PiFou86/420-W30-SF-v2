# Tests à écrire

Dans ce projet de tests, ajoutez les cinq méthodes de test demandées dans les
exercices 1 à 3. L’attribut xUnit `[Theory]` permet de regrouper plusieurs cas
de test sans multiplier les méthodes.

- E01 : une méthode paramétrée;
- E02 : une méthode paramétrée et un test de précondition du calculateur
  gratuit;
- E03 : conservez les trois méthodes précédentes et ajoutez deux tests de la
  classe `ServiceLivraisons` (délégation et précondition du constructeur).

Testez les comportements observables et conservez Arranger, Agir et Auditer.

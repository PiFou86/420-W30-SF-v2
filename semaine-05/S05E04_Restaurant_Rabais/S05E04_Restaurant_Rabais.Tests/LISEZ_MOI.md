# Tests à écrire

Dans ce projet de tests, créez exactement les sept méthodes de test demandées
dans l'énoncé, sans utiliser un conteneur d’injection de dépendances. Utilisez
une méthode de test xUnit marquée avec `[Theory]` pour regrouper les valeurs
limites du rabais fixe et une autre pour vérifier les deux ordres de la
stratégie composée.

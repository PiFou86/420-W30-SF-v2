# S05E04_Restaurant_Rabais

Cette solution .NET constitue le départ de l'exercice 4. Le projet principal
`S05E04_Restaurant_Rabais` contient un calcul conditionnel qui compile et qui
doit être remplacé par des classes de stratégies composables. Le projet de
tests recevra les six méthodes de test demandées dans l’énoncé. La solution ne
contient volontairement aucun projet Terminal.

```bash
dotnet test S05E04_Restaurant_Rabais.slnx
```
